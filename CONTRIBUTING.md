# Contributing to the Project

Thank you for your interest in contributing to this Python student project!

This guide explains how beginners can report problems, suggest improvements, make changes, and submit them to the project.

## 1. How to Report an Issue

If you find a problem:

1. Open the project's **Issues** section.
2. Create a new issue.
3. Give the issue a clear title.
4. Explain what went wrong.
5. Include the steps needed to reproduce the problem.

## 2. How to Suggest a Feature

If you have an idea for improving the project:

1. Open the project's **Issues** section.
2. Create a new issue.
3. Clearly describe the feature you suggest.
4. Explain why the feature would be useful.

## 3. How to Create a Branch

Create a separate branch before making changes.

```bash
git branch feature-name
git checkout feature-name
```

Use a short and meaningful branch name.

## 4. How to Make Changes

After creating a branch:

1. Make the required changes.
2. Keep the changes focused on one task.
3. Write clear and simple code.
4. Save your work.
5. Review the changes before submitting them.

## 5. How to Test Changes

Before submitting your changes:

1. Run the Python program.
2. Check that the program works correctly.
3. Test the changed features.
4. Make sure your changes do not cause new problems.

## 6. How to Create a Pull Request

After testing your changes:

1. Commit your changes.

```bash
git add .
git commit -m "Describe your changes"
```

2. Push your branch.

```bash
git push
```

3. Open a pull request.
4. Give the pull request a clear title.
5. Explain what you changed.
6. Submit the pull request for review.

## 7. Basic Coding Guidelines

Follow these simple guidelines:

- Use clear and meaningful names for variables and functions.
- Keep the code simple and easy to understand.
- Use proper indentation.
- Add comments when they are helpful.
- Avoid unnecessary code.
- Test your changes before submitting them.
- Keep each change focused on one task.

## Conclusion

Thank you for contributing to the project. Every contribution helps improve the project and provides a good learning experience.
