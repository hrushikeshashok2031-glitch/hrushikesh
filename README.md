# Student Grade Calculator

## Description

**Student Grade Calculator** is a beginner-level Python project designed to calculate student grades.

## Features

- Calculate student grades.
- Simple and beginner-friendly Python project.

## Requirements

- Python

## Installation

1. Install Python on your computer.
2. Create or open the project folder.
3. Add the project files.

## Usage

1. Open the project in a Python-compatible environment.
2. Run the program.
3. Enter the required student information.
4. View the calculated grade.

## Example

**Input:**
```text
Student marks
```

**Output:**
```text
Student grade
```
